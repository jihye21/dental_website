# dental_website

# DENTAL STUDIO | B2B 하이엔드 디지털 치과기공소 웹사이트

---

## 주요 특징 및 기능

- SPA 연동 멀티페이지 구조
  - 페이지 리로드 없이 부드러운 Fade-in 애니메이션 기반으로 [홈 / 기공소 소개 / 주요 기공 품목 / 디지털 워크플로우 / 파트너십 문의] 메뉴 간 즉각적인 전환 지원

- 반응형 디자인
  - 다양한 디바이스 해상도에 대응하는 그리드 및 타이포그래피 레이아웃

---

## 디자인

- Color Palette
  - Primary: Deep Navy (`#0B192C`) - 신뢰와 전문성
  - Accent: Steel Blue (`#243B53`) / Metallic Silver (`#CBD5E1`) - 정밀함과 고성능
  - Background: Pure White (`#FFFFFF`) & Very Light Gray (`#F8FAFC`) - 위생과 미니멀리즘

---

## 기술 스택 (Tech Stack)

- Markup & Styling: HTML5, Tailwind CSS
- Icons & Fonts: FontAwesome 6 Pro, Google Noto Sans KR / Inter
- Deployment: GitHub Pages
